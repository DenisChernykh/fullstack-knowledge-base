# Backend & Fullstack Knowledge Base

Структурированная техническая база знаний по backend- и fullstack-разработке.

## Возможности

- Темы backend, SQL, архитектуры и эксплуатации.
- Маршруты навигации по материалам и примеры из проектов.
- Автоматическая проверка структуры и полноты записей.

## Инженерные акценты

- Систематизация технических решений и аргументации.
- Связь фундаментальных механизмов с прикладными проектами.
- Автоматизация проверки документации как структурированных данных.

## Навигация по коду

- [docs/](docs/) — архитектура и документация.

## Разработка

Инструменты: pnpm@11.15.1.

```sh
pnpm install
pnpm check
pnpm test
```
